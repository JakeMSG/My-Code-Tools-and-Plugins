================ v1.3 - 7.2nd.2026
======== Changed settings transfer file from "Settings.json" to "ProgramSettings.json"
======== "Save plugins.js" now also toggles one trailing space before last "}" in data/System.json (MV: www/data/System.json, MZ: data/System.json) so editor detects change via data folder
======== Added plugin-parameter operations in Plugins column context menu (multi-select supported): save selected plugin parameters to plugins.js, export selected plugin parameters to Parameters_<PluginName>.json, import selected plugin parameters from Parameters_<PluginName>.json
======== Added Tab+S / Tab+Shift+S / Tab+Ctrl+S / Tab+Shift+Ctrl+S / Tab+Alt+S / Tab+Shift+Alt+S hotkeys for active-tab and opened-tab plugin parameter save/export/import operations
======== Added plugins.js external modification detector (1-second polling + window-focus check) with popup options: Reload, Ignore, Reload EXCEPT the opened plugins
