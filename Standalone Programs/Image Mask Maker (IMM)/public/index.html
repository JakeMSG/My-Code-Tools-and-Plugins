    Align pictures

    Offset each picture so the same part of the character lines up. The mask you draw next is shared. Each saved mask is cut from that drawing at the picture’s offset, so the white areas will not sit on the same pixels in every file.

    Select a picture, then drag it or nudge it.

    Dragging moves the selected picture, including where a later picture covers it. A drag that starts outside that picture selects and moves the top picture under the pointer. Drag empty space to pan. Mouse wheel zooms. Arrow keys nudge by 1 pixel (Shift = 10).

      Draw the mask

      White is the area to redraw. Gray softens the edge. Black is left as it is. On screen, white and gray are a see-through tint so the picture stays visible. The saved file is an opaque black, white, and gray PNG or WebP, in the same format as the picture.
